# 42 School Projects (`42_Projects`)

This repository is a collection of low-level systems, C/C++ programming, algorithms, and UNIX infrastructure projects that I developed **while learning software development** during my intensive training at **42 Kocaeli**.

All sub-projects preserve their original Git commit history and stand as a concrete demonstration of my foundational skills in memory management, concurrent programming, and operating system concepts.

---

## 🛠️ Project Showcase & Core Capabilities

| Project | Language | Key Concepts & Skills Learned |
| :--- | :---: | :--- |
| **[Libft](./Libft)** | C | Custom C standard library implementation, raw memory manipulation (`memcpy`, `memmove`), custom data structures (linked lists), and pointer arithmetic. |
| **[GetNextLine](./GetNextLine)** | C | File descriptor handling, static variables, buffer management, and dynamic memory allocation. |
| **[Printf](./Printf)** | C | Variadic functions (`va_list`), string formatting, and number base conversions. |
| **[Push_Swap](./Push_Swap)** | C | Algorithmic optimization, stack operations, sorting algorithms, and complexity reduction ($O(n \log n)$). |
| **[mini_talk](./mini_talk)** | C / POSIX | UNIX inter-process communication (IPC) using POSIX signals (`SIGUSR1`, `SIGUSR2`) and bitwise operations. |
| **[So_long](./So_long)** | C | 2D game engine development, graphics rendering with MiniLibX, event handling, and map parsing (`.ber`). |
| **[Philosophers42](./Philosophers42)** | C | Thread management, mutexes, deadlock prevention, race condition handling, and classic dining philosophers synchronization. |
| **[Minishell42](./Minishell42)** | C | Building a custom UNIX Shell: Process control (`fork`, `execve`), pipes, file redirection, signal handling, and AST tokenization. |
| **[CPP42](./CPP42)** | C++ (98/11) | Object-Oriented Programming (OOP), Orthodox Canonical Form, inheritance, polymorphism, templates, and C++ Standard Template Library (STL). |
